# AI-Backlog-Radar

AI value-chain backlog (RPO, remaining performance obligation) tracker built from SEC EDGAR XBRL public APIs.

- Page: index.html (GitHub Pages)
- Data: data/backlog.json (rebuilt by GitHub Actions, weekdays 21:30 UTC)
- Tickers: config/universe.json
- Required secret: SEC_USER_AGENT (e.g. "SJ Market Desk yourname@example.com")
